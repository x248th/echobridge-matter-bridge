# echobridge-matter-bridge

EchoBridge（Panasonic リンクプラス照明ブリッジ）本体の **Matter アドオン**。
本体が管理している照明とシーンを Matter ブリッジとして公開し、スマートホームの
アプリから操作できるようにする。

## 位置づけ

- **テスト用のアドオンです。CSA（Matter）の認証は取得していません。**
- そのため、ホームアプリへ追加するときに「認定されていないアクセサリ」の警告が出ます。
  そのまま追加すれば使えます（仕様です）。
- 動作の完成・継続を保証するものではありません。
- **動作を確認しているのは Apple Home です。** ほかの Matter コントローラでの動作は
  確かめていません。

## 必要なもの

- EchoBridge 本体が同じ機体で稼働していること（`:8099`）
- Node.js 22 LTS（`npm` も使います）
- Apple Home で使う場合は、ホームハブ（Apple TV / HomePod 等）

## 導入

本体の管理画面から、スマートホーム連携（β版）の **インストール** ボタンで導入します。
起動・停止・アンインストールも本体の管理画面から行います。

## アンインストールとペアリング情報

- **アンインストールしてもペアリング情報は残ります**（本機に保存されます）。
  再インストールすると、ホームアプリに登録したまま使えます。
- 設定を消すには、アンインストールしたあと、本体の管理画面のスマートホーム連携（β版）の
  カードに出る「残っている設定を削除」を押します。（本体の「アドオンをすべて削除」は、
  **ほかのアドオンの設定もまとめて消す**ので、この用途には使わないでください。）
- ホームアプリから削除して登録し直す場合は、次の順に行ってください。
  1. ホームアプリからブリッジを削除する
  2. 本体の管理画面でアンインストールする
  3. カードに出る「残っている設定を削除」を押す
  4. インストールする

### v1.0.2 以前から更新する場合

**ホームアプリへの登録し直しが1回必要です。** v1.0.2 以前はペアリング情報の置き場所が
違うため、更新（アンインストール→インストール）で消えます。ホームアプリに残った古い
ブリッジを削除し、管理画面のカードに出る新しい QR / PIN で追加し直してください。
